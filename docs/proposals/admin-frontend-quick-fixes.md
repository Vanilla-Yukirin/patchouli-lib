# 管理前端小修清单

- 状态：提案中（Proposed）
- 范围：只修改现有 Python 渲染的 `/admin` 页面、样式与内嵌脚本；不新增依赖，不改变
  数据库、接口契约或安全响应头

## 原则

- 旧页面最终会被[新前端](admin-frontend-migration.md)替换，小修只做改动小、
  收益明确、风险低的修正，不做结构性重构。
- 每项可以独立提交和审查；涉及文案的改动同时更新中英文。
- 不放宽 CSP；需要脚本的改动沿用现有同源 `/admin/*.js` 方式。

## 清单

按建议顺序排列。

### Q1 默认语言跟随浏览器

- 现状：未选择语言时固定为英文。
- 改动：没有 `lang` 查询参数和语言 Cookie 时，按 `Accept-Language` 在 `zh-CN`
  与 `en` 之间选择；无法匹配时仍为英文。
- 验证：分别覆盖查询参数、Cookie、`Accept-Language` 与默认值的优先级。

### Q2 按浏览器时区显示时间

- 现状：时间固定显示为 UTC。
- 改动：服务端继续输出带 `datetime` 属性的 `<time>` 元素和 UTC 文本作为无脚本
  回退；新增一个同源小脚本，用 `Intl.DateTimeFormat` 按浏览器时区格式化，并在
  `title` 中保留 UTC 原值。不写死任何固定时差。
- 验证：在不同浏览器时区下核对跨日日期；无脚本时仍显示 UTC。

### Q3 发生时间输入辅助

- 现状：要求手写 RFC3339 文本。
- 改动：保留文本字段作为提交值，增加 `datetime-local` 辅助输入，由脚本按浏览器
  时区换算为带 `Z` 的 UTC 值写入文本字段，并在旁边显示换算结果。
- 验证：覆盖跨日、夏令时地区和手动输入文本的情况。

### Q4 导航去重与分组

- 按[工作区产品需求](library-workspace-and-skills.md)将全局功能集中到顶部，分组
  提供内容、管理和接入入口；窄屏可折叠，不在左侧重复相同菜单。
- “API 请求” 在有权限时提供稳定的管理入口，不只在当前页才出现。
- 小修不新建完整目录树；左侧留给新前端的分区阅读目录，不再承担全局导航。

### Q5 页面详情的操作分层

- “更新文件”、“移动文档”、“恢复此版本” 保留为可见操作；
- 改标题、改发生时间、管理标签收进默认折叠的 `<details>`；
- 移入回收站单独放在页面底部的危险区域，使用 `.danger` 样式。

### Q6 提示与错误语义

- 错误提示改用 `role="alert"`，普通提示保留 `role="status"`；
- 表单校验失败时，提示放在对应表单附近，并保留用户已输入的值（凭据字段除外）。

### Q7 危险按钮样式统一

- 所有删除、吊销、停用、移入回收站按钮统一使用 `.danger`；
- 主要操作、次要操作与链接的样式按语义区分，减少把链接做成按钮的情况。

### Q8 技术信息降级显示

- 文件列表中字节数改为人类可读单位（KB、MB），原始字节数放进 `title`；
- SHA-256 等技术信息收进默认折叠的 “技术详情”。

## 不在小修范围内

以下问题需要新前端才能妥善解决，不在旧页面上处理：目录树、局部刷新与乐观更新、
拖放上传与进度、命令面板、版本差异对比、网页内编辑、暗色模式。
