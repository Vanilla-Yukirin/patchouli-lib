# 标签浏览与批量管理

状态：本轮本地实现方案；提交、合并和部署单独进行。

## 浏览

- 全局标签页直接列出标签，显示所属知识库及未删除页面数量；同名跨库标签保持独立。
- 标签使用可换行的圆角标签样式；点击直接进入详情，不要求先选择知识库。
- 详情展示关联的未删除页面；目录不展开全部关联页面。
- 知识库详情直接显示自己的标签，并提供按钮式管理入口。
- 知识库回收站按钮显示已删除 Page 数量，历史 Revision 不单独计数。
- 没有标签时明确显示空状态。跳转保留链接语义与键盘操作，视觉采用按钮样式。

## 批量管理

- 不添加备注字段，不新增数据库迁移。
- 全局标签页提供关键词、知识库筛选和当前显示项全选；筛选隐藏的项取消选择。
- 主会话可勾选后逐项填新名称，一次提交最多 200 个标签；全部预检通过才原子执行。
- 保留现有名称规范化、长度和同库唯一约束。冲突、互换名字或并发改名返回提示，不自动合并。
- 删除必须显式勾选确认；删除标签定义及所有关联，包括回收站页面上的关联。
- 删除标签不可从页面回收站恢复；页面正文、版本和历史审计保留，完整数据库备份可恢复旧状态。
- 请求仍需会话鉴权、同源提交、CSRF、事务内复查。提交原标签名作为并发检查条件。
- 审计记录 `tag.rename` / `tag.delete` 和对象 ID；既有 Agent 标签 API 保持原契约。
- 搜索使用更新后的标签定义及关联；使用现有触发器刷新索引，不遗留已删除标签的搜索匹配。

## 验证

覆盖跨知识库同名标签、零标签、长名称转义、回收站删除/恢复计数、详情跳转、
批量改名/删除/并发冲突/鉴权、真实迁移库上的索引更新和备份恢复。
