# Agent Token 的可选无限有效期

状态：本次实现提案；合并与部署分别验收。

## 目标与范围

后台通过主 Token 会话创建或轮换 Agent Token 时，可以明确选择「永不过期」。
默认仍为一年，也可填写自定义秒数。归属知识库与逐知识库读写授权保持独立；
本提案不增加自动获得所有知识库权限的模式，也不改变管理登录会话的有效期。

## 输入与表示

- 创建及轮换表单增加 `never_expires` 复选框，默认不选。
- 未选时必须提交正整数 `credential_ttl_seconds`；不能把空值、零、负数或错误
  输入解释成无限。选中时秒数不参与计算，界面明确说明这一点，无 JavaScript 也可提交。
- 数据库存储 `expires_at = NULL`，表示没有到期时间。现有有限日期不转换。
- `GET /api/v1/auth/whoami` 的 `expires_at` 对此类凭据返回 JSON `null`；有限
  凭据继续返回原来的 RFC 3339 UTC 字符串。Python 客户端同步接受可空值。
- 凭据详情明确显示「永不过期」，不显示一个很远的虚构截止日期。

## 授权与生命周期

无期限凭据仍必须通过签名校验、身份启用状态、吊销和轮换状态以及逐库授权检查。
下载、搜索、管理操作和事务内授权复查均采用相同语义。可以将有限凭据轮换为
无限凭据，也可以反向轮换；新凭据保留原授权，旧凭据立即失效。

无限签发仅从主会话的 Agent 创建及轮换入口开放；旧 Operator 签发命令仍要求有限
有效期。主 Token、浏览器会话与一次性设置凭据不受本提案影响。

## 迁移与恢复

新迁移允许凭据到期时间为空，并调整最后使用时间约束。升级保留现有身份、凭据、
授权、审计与内容数据。备份必须识别新结构、完整保留空到期值，同时继续验证旧版本
备份。存在任何空到期值时拒绝降级，不能在回退时偷偷设置期限或删除凭据。

## 验收

- 默认一年、自定义十年、无限模式以及错误输入校验。
- 有限到期边界不变；无限凭据的鉴权、读取、搜索、再次显示、轮换与吊销有效。
- 中英文创建及轮换表单和详情显示；旧表单提交兼容。
- API、Python 客户端的空值与有限时间解析。
- 带数据迁移、外键检查、备份与恢复、降级拒绝及有限数据的可逆升级。

本功能不自动修改已有 Token，不自动发布或更新部署。
