# 管理前端交互规范

- 状态：产品交互已确认；具体组件与接口仍为提案中（Proposed），尚未实现。
- 范围：新管理前端的信息架构、页面结构与通用交互模式，详细产品要求以
  [知识库工作区与库内 Skills](library-workspace-and-skills.md)为准。

## 信息架构

### 应用外壳

- **顶部栏**：集中全局功能与语言、主题、退出；入口按内容、管理、接入分组，窄屏
  使用折叠菜单，不将全部入口硬排成一行。
- **左侧栏**：只承担当前分区的书籍/页面目录，可折叠；不重复顶部全局菜单。
  窄屏使用目录抽屉，保留相同业务能力。
- **面包屑**：位于内容区顶部，每一级都可点击返回。
- **工作区切换**：常规导航、编辑和结果反馈局部更新，同时保留深链接、刷新直达与
  前进后退；URL 用于定位，不要求用户手动操作内部路径。

### 导航分组

| 顶部导航分组 | 内容 |
| --- | --- |
| 内容 | 首页、知识库、搜索、标签、回收站 |
| 管理 | 凭据、API 请求、初始化与凭据 |
| 接入 | 指南、Agent、MCP |

库外搜索是全局入口；知识库内的入口明确显示当前库，默认限该库。两者复用同一
检索服务和知识库筛选条件，无结果时不自动扩大范围。

### 首页

- 概览：知识库、页面与凭据数量；
- 需要处理：即将过期的凭据、未就绪的搜索索引等；
- 最近活动：沿用现有内容活动时间线；
- 快捷入口：新建文档、搜索、创建凭据。

## 页面结构

### 知识库概览

- 顶部为名称、描述和操作入口；README、Skills 各有明确板块，可摘要展示再展开。
- 板块通过标题、背景、边界和留白形成清晰层级，不把说明、配置和文档连续平铺。
- 下方以分区卡片展示用途并进入分区；空库提供 README、Skills 和结构设置引导。
- 进入知识库始终先看概览，不自动恢复为某篇文档。

### 分区阅读工作区

- 左侧展开书籍和页面，右侧阅读；不必每展开一级就进入一张管理页。
- 分区与书籍 README、用途仍可查看编辑，创建/修改表单按需打开，不常驻抢占正文。
- 可在分区内保留最后页面、阅读位置和目录展开；只保存轻量定位，不保存正文或凭据，
  不建立全局阅读轨迹，不让这些状态跳过知识库概览。

### 文档（Page）

以标签页组织：

| 标签页 | 内容 |
| --- | --- |
| 内容 | 默认安全渲染主文档；可切换文件，文本提供编辑按钮 |
| 文件 | 文件列表、下载、上传、替换、改名及插入引用，默认保留未改附件 |
| 历史 | 版本时间线，选择任意两个版本查看差异，一键恢复 |
| 属性 | 发生时间、标签及默认折叠的技术信息；危险操作与常规属性分开 |

展示标题跟随主文档的第一个一级标题，并保留弱化 `#` 标记；文件名另行以次级文字
显示。无标题时回退主文件名，不额外要求维护独立网页标题。保存后列表、搜索与阅读
同步使用新标题，历史版本仍显示其自身标题；稳定 ID 和文件名不随标题自动改变。

主文档优先采用显式选择，单篇自动显示，多篇未指定时寻找 README；仍不明确则
保留文件选择入口，不以“文件必须叫 content.md”为阅读前提。候选排序及旧数据
兼容按上述产品需求补齐实现契约。

### 文本编辑与附件引用

- 能安全解析为文本的文件均可编辑；桌面源码与实时预览左右分栏，窄屏切换显示。
- 只有点击“保存”才提交正式文件组版本，保留未改附件；输入只暂留当前前端页面。
- 不自动保存，不建设持久或跨设备草稿；离开未保存编辑区时简单提醒。
- 附件改名列出当前文件集内 Markdown 引用，展示文件、行列、上下文和前后对照，
  确定的修改默认全选，允许逐项取消；可能失效的引用单独提醒。
- “应用”先调整编辑区，最终“保存”把改名与所选引用一次提交；不盲改代码/普通
  文字，不修改历史或跨 Page 自动替换。

### 库内 Skills

知识库有独立 Skills 入口，每个具名 Skill 包含 `SKILL.md`、脚本、JSON 和附件，
可显示包内目录。不要求为它创建占位分区或书籍，不做跨库共享联动。

点击 README 的 Skill 链接直接查看详情；管理员使用既有网页登录态编辑、保存、
复制和下载。保存发布新版本后，Agent 可下载，不依赖重新部署应用镜像。
本机仍正式安装 Skill，新任务首次访问库时读 README 与线上版本；新版自行校验更新，
本机与线上分叉时展示差异由用户决定。具体实体、接口和兼容迁移另行审查。

## 通用交互模式

### 反馈

- 写操作成功后以 Toast 提示；后端已有可靠逆操作时，可在提示中提供“撤销”，
  不能仅靠前端文字承诺尚不存在的恢复能力。
- 失败时：字段错误显示在字段旁；并发冲突（版本已变化）提示重新加载并保留用户
  输入；其他错误以 Toast 或页面内警告显示，使用 `role="alert"`。
- 加载时使用骨架屏，避免整页空白；不使用整页刷新。
- 过渡动画短且不阻塞操作，尊重减少动态效果设置。

### 危险操作

- 删除、吊销、停用等操作统一使用危险样式，并通过确认对话框执行；
- 不可逆或影响面大的操作（吊销凭据、永久删除）在对话框中写明影响范围，必要时
  要求输入名称确认。

### 时间

- 默认按浏览器时区显示，悬停显示 UTC 原值；
- 时间输入使用日期时间选择器，界面同时显示本地时间与将提交的 UTC 值。

### 上传

- 支持拖放与多选，显示上传队列与逐文件进度；
- 幂等键和重试机制内部处理；界面区分“保存中／已保存／明确失败／结果待确认”，
  不把结果未知误报为失败再盲目新建；
- 页面刷新后若存在未确认的操作，明确提示并引导重新选择文件。

### 命令面板

- Ctrl/Cmd+K 打开，支持搜索文档、跳转到知识库与设置页、执行常用操作；
- 搜索继承当前位置：库内默认当前库，库外全局；索引未就绪时明确提示。

### 凭据与 Token

- 一次性接入结果在原上下文内显示并提供复制按钮，标明真实有效期和可再次查看能力；
  不把所有长期凭据都描述为关闭后无法再次查看；
- Token 只存在于输入框和当次请求中，不进入状态缓存、URL 或浏览器存储。

### 技术信息

- SHA-256、原始字节数、内部 ID 等放在默认折叠的 “技术详情” 中，并提供复制按钮。

## 可访问性

- 保持现有水平：所有控件有可访问名称，焦点可见，键盘可完成全部操作；
- 对话框、菜单、标签页使用 Radix 提供的焦点管理与键盘交互；
- 保留强制颜色模式下的可辨识性；颜色不作为唯一的状态区分方式。

## 多语言

- 首次访问按 `Accept-Language` 选择 `zh-CN` 或 `en`，用户切换后记住偏好；
- 文案使用语义化键，中英文同时维护；不再以英文原文为键。
- 语言偏好对阅读、编辑、上传、保存反馈及后续导航一致生效，不仅修改当前 URL。

## 响应式功能完整性

手机、平板、桌面保留相同的阅读、编辑、附件、Skills 与配置管理能力，通过布局
适配实现。目录和全局导航可收起；长文件名、提示和操作区应可重排，不以横向拖动
整个页面作为常规操作方式。
