# 管理前端交互规范

- 状态：提案中（Proposed）
- 范围：新管理前端的信息架构、页面结构与通用交互模式；视觉细节在实现时用组件库
  默认主题起步，另行迭代

## 信息架构

### 应用外壳

- **左侧栏**：上方为分组导航，下方为可折叠的内容目录树（知识库 › 分区 › 书籍），
  宽度可拖动调整并记住偏好（仅记界面偏好，不记凭据）。
- **顶部栏**：全局搜索入口（同时是命令面板入口）、语言切换、主题切换、退出。
  不重复侧栏中的导航项。
- **面包屑**：位于内容区顶部，每一级都可点击返回。

### 导航分组

| 分组 | 内容 |
| --- | --- |
| 内容 | 首页、知识库、搜索、标签、回收站 |
| 管理 | 凭据、API 请求、初始化与凭据 |
| 接入 | 指南、Agent、MCP |

### 首页

- 概览：知识库、页面与凭据数量；
- 需要处理：即将过期的凭据、未就绪的搜索索引等；
- 最近活动：沿用现有内容活动时间线；
- 快捷入口：新建文档、搜索、创建凭据。

## 页面结构

### 知识库、分区、书籍

- 顶部为名称、摘要和 “⋯” 操作菜单（编辑、README、移动、删除等）；
- 子项以表格展示，支持排序、筛选、多选与批量操作；
- README 以渲染后的形式显示，可原地切换为编辑。

### 文档（Page）

以标签页组织：

| 标签页 | 内容 |
| --- | --- |
| 内容 | 默认显示渲染后的 Markdown；多文件时可切换文件 |
| 文件 | 文件列表、下载、更新文件（拖放上传） |
| 历史 | 版本时间线，选择任意两个版本查看差异，一键恢复 |
| 设置 | 标题、发生时间、标签；底部危险区域：移入回收站 |

标题可在页面顶部原地编辑；主要操作（更新文件、移动）放在顶部，低频操作收进
“⋯” 菜单。

## 通用交互模式

### 反馈

- 写操作成功后以 Toast 提示；可逆操作（移入回收站、移动、标签变更）在 Toast 中
  提供 “撤销”。
- 失败时：字段错误显示在字段旁；并发冲突（版本已变化）提示重新加载并保留用户
  输入；其他错误以 Toast 或页面内警告显示，使用 `role="alert"`。
- 加载时使用骨架屏，避免整页空白；不使用整页刷新。

### 危险操作

- 删除、吊销、停用等操作统一使用危险样式，并通过确认对话框执行；
- 不可逆或影响面大的操作（吊销凭据、永久删除）在对话框中写明影响范围，必要时
  要求输入名称确认。

### 时间

- 默认按浏览器时区显示，悬停显示 UTC 原值；
- 时间输入使用日期时间选择器，界面同时显示本地时间与将提交的 UTC 值。

### 上传

- 支持拖放与多选，显示上传队列与逐文件进度；
- 幂等键、重试与 “结果未知” 的处理在内部完成，只向用户展示 “已保存／保存中／
  失败，可重试” 三类状态；
- 页面刷新后若存在未确认的操作，明确提示并引导重新选择文件。

### 命令面板

- Ctrl/Cmd+K 打开，支持搜索文档、跳转到知识库与设置页、执行常用操作；
- 搜索结果复用当前 Page 搜索接口，索引未就绪时给出明确提示。

### 凭据与 Token

- 一次性凭据结果使用独立对话框或页面，显示复制按钮与 “我已保存” 确认，关闭前
  提醒无法再次查看；
- Token 只存在于输入框和当次请求中，不进入状态缓存、URL 或浏览器存储。

### 技术信息

- SHA-256、原始字节数、内部 ID 等放在默认折叠的 “技术详情” 中，并提供复制按钮。

## 可访问性

- 保持现有水平：所有控件有可访问名称，焦点可见，键盘可完成全部操作；
- 对话框、菜单、标签页使用 Radix 提供的焦点管理与键盘交互；
- 保留强制颜色模式下的可辨识性；颜色不作为唯一的状态区分方式。

## 多语言

- 首次访问按 `Accept-Language` 选择 `zh-CN` 或 `en`，用户切换后记住偏好；
- 文案使用语义化键，中英文同时维护；不再以英文原文为键。
