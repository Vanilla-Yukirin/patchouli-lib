# 管理前端交互规范

- 状态：产品交互已确认；具体组件与接口仍为提案中（Proposed），尚未实现。
- 范围：新管理前端的信息架构、页面结构、内容操作流程与通用交互模式，详细产品要求以
  [知识库工作区与库内 Skills](library-workspace-and-skills.md)为准。

本文中的“入口文件”指一个文档版本中被默认阅读、并提供展示标题的文件，接口字段
暂称 `primary_file`；定义见产品需求。

## 信息架构

### 应用外壳

- **顶部栏**：集中全局功能与语言、主题、退出；入口按内容、管理、接入分组，窄屏
  使用折叠菜单，不将全部入口硬排成一行。
- **左侧栏**：只承担当前分区的书籍/页面目录，可折叠；不重复顶部全局菜单。
  窄屏使用目录抽屉，保留相同业务能力。
- **面包屑**：位于内容区顶部，每一级都可点击返回。
- **工作区切换**：常规导航、编辑和结果反馈局部更新，同时保留深链接、刷新直达与
  前进后退；URL 用于定位，不要求用户手动操作内部路径。

### 导航分组

| 顶部导航分组 | 内容 |
| --- | --- |
| 内容 | 首页、知识库、搜索、标签、回收站 |
| 管理 | 凭据、API 请求、初始化与凭据 |
| 接入 | 指南、Agent、MCP |

库外搜索是全局入口；知识库内的入口明确显示当前库，默认限该库。两者复用同一
检索服务和知识库筛选条件，无结果时不自动扩大范围。

### 首页

- 概览：知识库、页面与凭据数量；
- 需要处理：即将过期的凭据、未就绪的搜索索引等；
- 最近活动：沿用现有内容活动时间线；
- 快捷入口：新建文档、搜索、创建凭据。

## 页面结构

### 知识库概览

- 顶部为名称、描述和操作入口；README、Skills 各有明确板块，可摘要展示再展开。
- 板块通过标题、背景、边界和留白形成清晰层级，不把说明、配置和文档连续平铺。
- 下方以分区卡片展示用途并进入分区；空库提供 README、Skills 和结构设置引导。
- 进入知识库始终先看概览，不自动恢复为某篇文档。

### 分区阅读工作区

- 左侧展开书籍和页面，右侧阅读；不必每展开一级就进入一张管理页。
- 分区与书籍 README、用途仍可查看编辑，创建/修改表单按需打开，不常驻抢占正文。
- 可在分区内保留最后页面、阅读位置和目录展开；只保存轻量定位，不保存正文或凭据，
  不建立全局阅读轨迹，不让这些状态跳过知识库概览。

### 文档（Page）

以标签页组织：

| 标签页 | 内容 |
| --- | --- |
| 内容 | 默认安全渲染入口文件；可切换文件，文本提供编辑按钮 |
| 文件 | 文件列表、下载、上传、替换、改名、设置入口文件及插入引用，默认保留未改附件 |
| 历史 | 版本时间线，选择任意两个版本查看差异，一键恢复 |
| 属性 | 发生时间、标签及默认折叠的技术信息；危险操作与常规属性分开 |

展示标题来自该版本入口文件的第一个一级标题，并保留弱化 `#` 标记；文件名另行以次级
文字显示。标题在每次写入文件集时确定并随版本保存，列表、搜索与阅读读取已保存的
标题；历史版本显示其自身标题。提取不到标题时显示“无标题”，不回退为文件名，也
不要求维护独立网页标题。稳定 ID 和文件名不随标题自动改变。

**无入口文件**：版本没有入口文件（Agent 未指定，或旧数据）时，内容页显示“此文档
未指定入口文件”，列出文件并提供“设为入口文件”，不按文件名或数量猜测。展示标题
为“无标题”。

### 文本编辑与附件引用

- 能安全解析为文本的文件均可编辑；桌面源码与实时预览左右分栏，窄屏切换显示。
- 预览与阅读使用同一个前端 Markdown 渲染器，所见即所得；编辑区上方实时显示将
  使用的标题（或“无标题”）。
- 只有点击“保存”才提交正式文件组版本，保留未改附件；输入只暂留当前前端页面。
- 不自动保存，不建设持久或跨设备草稿；离开未保存编辑区时简单提醒。
- **保存冲突时直接覆盖**：保存时若文档在打开后已有更新版本，仍以当前输入作为
  新的最新版本提交，不拒绝、不做合并界面。成功提示附注“保存时文档已有更新版本，
  已被本次保存取代，可在历史中找回”。被取代的版本保留在历史中。
- 附件改名列出当前文件集内 Markdown 引用，展示文件、行列、上下文和前后对照，
  确定的修改默认全选，允许逐项取消；可能失效的引用单独提醒。
- “应用”先调整编辑区，最终“保存”把改名与所选引用一次提交；不盲改代码/普通
  文字，不修改历史或跨 Page 自动替换。
- 窄屏的引用修改窗口使用全屏面板，底部固定“应用”和“取消”。

### 库内 Skills

知识库有独立 Skills 入口，每个具名 Skill 包含 `SKILL.md`、脚本、JSON 和附件，
可显示包内目录。不要求为它创建占位分区或书籍，不做跨库共享联动。

点击 README 的 Skill 链接直接查看详情；管理员使用既有网页登录态编辑、保存、
复制和下载。保存发布新版本后，Agent 可下载，不依赖重新部署应用镜像。
本机仍正式安装 Skill，新任务首次访问库时读 README 与线上版本；新版自行校验更新，
本机与线上分叉时展示差异由用户决定。具体实体、接口和兼容迁移另行审查。

## 内容操作流程

以下流程针对主 Token 会话；各操作的成功结果不要求用户理解操作键或 ETag，
“结果待确认”时沿用原操作重试，不静默改为新操作。

### 新建文档

1. 入口：书籍阅读视图顶部的“新建文档”，或目录树中书籍行的“⋯”菜单。目标书籍
   取自当前位置，可在对话中通过目录选择器更改。
2. 进入完整编辑工作区（不是弹窗）：左侧文件列表，中间源码，右侧预览。初始有一个
   可改名的文本文件（默认文件名在原型中确定）；可继续“添加文件”——拖放、选择
   上传，或新建文本文件。
3. 入口文件：默认选中第一个可预览文本文件，可在文件列表中改选。没有可预览文件时
   允许保存，但提示“未指定入口文件”。
4. 没有独立的标题输入框；预览上方显示将使用的标题，来源提示为“来自正文第一个
   一级标题”。
5. 发生时间默认由服务端取接收时间，可展开“更改发生时间”，使用日期时间选择器，
   同时显示本地时间和将提交的 UTC 值。
6. 点击“保存”创建；成功后进入阅读视图并提示。离开未保存内容时简单提醒。

### 移动文档

1. 入口：文档页顶部“⋯”→“移动到…”；桌面指针设备还可在目录树内拖动文档到目标
   书籍。触屏和键盘使用菜单，不要求拖动。
2. 对话框用目录树选择目标书籍，仅限同一知识库，可跨分区；其他知识库的书籍显示为
   不可选并说明原因。对话框写明“从 A / B 到 C / D”，并说明文档 ID、历史、标签和
   发生时间不变，不产生新版本。
3. 目标与当前相同时提示“已在该书籍中”，不提交。
4. 成功后目录树即时更新，当前文档保持打开，原链接继续可用。

### 删除与回收站

1. 入口：文档页“⋯”→“移入回收站”，确认对话框说明“全部版本和文件保留，可在回收站
   恢复”。因为存在可靠的恢复操作，成功提示提供“撤销”。
2. 回收站（内容分组）按删除时间由新到旧列出已删除文档的标题、原位置和删除时间，
   可按知识库筛选并继续加载。回收站不读取正文，详情只显示元信息。
3. “恢复”后文档回到原位置，保留原 ID 和全部历史；无法回到原位置时说明原因。
4. 本轮不提供永久删除。

### 恢复历史版本

历史标签页选择某个版本，可先“与当前对比”，再点击“恢复此版本”。对话框说明将以该
版本的全部文件生成一个新版本，旧版本保留；内容与当前相同时不新增版本，并如实提示。

### 标签

- 文档“属性”页用标签输入框选择本知识库已有标签，添加或移除即时保存，失败时回滚并
  提示；知识库没有标签时引导到标签管理创建。
- 标签管理页（内容分组）为全局表格：筛选、多选、批量改名和批量删除。删除前确认数量，
  并说明“只移除标签与关联，文档和历史保留”。

### README、用途与描述

知识库、分区、书籍的描述与 README 在各自板块点击“编辑”后原位展开，使用同一文本
编辑器（源码与预览），点击“保存”提交；离开未保存内容时简单提醒。

## 身份与权限呈现

新界面只有一种管理会话：**主 Token 会话**。不再有密码登录和密码会话。

- 全新安装首次进入时只有“设置主 Token”一个入口；设置完成后即处于主 Token 会话，
  再进行其他任何操作。之后登录只需输入主 Token，不需要用户名。
- 主 Token 是万能凭据：所有网页写操作都不再要求另填 Operator Token，新界面没有
  Operator Token 输入框。
- 未登录时只能看到登录页（已设置主 Token）或首次设置页（尚未设置）。

首次设置仍须出示部署者配置的一次性设置令牌，否则最先访问空实例的人就能占有它；
现有安装如何过渡见[总览开放问题 2](admin-frontend-rebuild.md#开放问题)。
任何情况下 Token 只存在于输入框和当次请求中，不进入状态缓存、URL 或浏览器存储。

## 通用交互模式

### 反馈

- 写操作成功后以 Toast 提示；后端已有可靠逆操作时（如移入回收站可恢复），可在
  提示中提供“撤销”，不能仅靠前端文字承诺尚不存在的恢复能力。
- 失败时：字段错误显示在字段旁；其他错误以 Toast 或页面内警告显示，使用
  `role="alert"`。
- 移动、移入回收站、标签变更等非文本写操作仍由服务端校验页面是否已变化；被拒绝时
  界面刷新数据并提示“文档已更新，请确认后重试”。
- 加载时使用骨架屏，避免整页空白；不使用整页刷新。
- 过渡动画短且不阻塞操作，尊重减少动态效果设置。

### 危险操作

- 删除、吊销、停用等操作统一使用危险样式，并通过确认对话框执行；
- 不可逆或影响面大的操作（吊销凭据）在对话框中写明影响范围，必要时要求输入名称
  确认。

### 时间

- 默认按浏览器时区显示，悬停显示 UTC 原值；
- 时间输入使用日期时间选择器，界面同时显示本地时间与将提交的 UTC 值。

### 上传

- 支持拖放与多选，显示上传队列与逐文件进度；
- 幂等键和重试机制内部处理；界面区分“保存中／已保存／明确失败／结果待确认”，
  不把结果未知误报为失败再盲目新建；
- 页面刷新后若存在未确认的操作，明确提示并引导重新选择文件。

### 命令面板

- Ctrl/Cmd+K 打开，支持搜索文档、跳转到知识库与设置页、执行常用操作；
- 搜索继承当前位置：库内默认当前库，库外全局；索引未就绪时明确提示。

### 凭据与 Token

- 一次性接入结果在原上下文内显示并提供复制按钮，标明真实有效期和可再次查看能力；
  不把所有长期凭据都描述为关闭后无法再次查看；
- Token 只存在于输入框和当次请求中，不进入状态缓存、URL 或浏览器存储。

### 技术信息

- SHA-256、原始字节数、内部 ID 等放在默认折叠的“技术详情”中，并提供复制按钮。

## 触屏与响应式

手机、平板、桌面保留相同的阅读、编辑、附件、Skills 与配置管理能力，通过布局
适配实现，并支持触屏操作：

- 可点击控件的触控目标不小于 44×44 CSS 像素，相邻操作之间留出间距；
- 不依赖悬停才能出现的操作；悬停菜单在触屏上必须可见或收进“⋯”菜单；
- 所有拖放操作（目录树移动、文件上传）都有不需要拖动的菜单或文件选择替代；
- 目录和全局导航可收起，窄屏目录用抽屉；编辑器窄屏用“编辑／预览”分段切换；
- 长文件名、提示和操作区应可重排，不以横向拖动整个页面作为常规操作方式；
- 手势不作为唯一入口。

## 可访问性

- 保持现有水平：所有控件有可访问名称，焦点可见，键盘可完成全部操作；
- 对话框、菜单、标签页使用 Radix 提供的焦点管理与键盘交互；
- 保留强制颜色模式下的可辨识性；颜色不作为唯一的状态区分方式。

## 多语言

- 首次访问按 `Accept-Language` 选择 `zh-CN` 或 `en`，用户切换后记住偏好；
- 文案使用语义化键，中英文同时维护；不再以英文原文为键；
- 语言偏好对阅读、编辑、上传、保存反馈及后续导航一致生效，不仅修改当前 URL。
