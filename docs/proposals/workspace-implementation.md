# 知识库工作区实现契约

- 状态：本轮实现契约，验收后更新实施证据
- 依据：[产品需求](library-workspace-and-skills.md)与 [ADR 0005](../decisions/0005-library-workspace.md)

## 入口与版本

`revision_presentations` 以知识库、页面、准确 Revision 身份为键，追加保存
`primary_file` 和 `display_title`。旧 Revision 不回填推断值，网页显示无入口与无标题。
正文和既有独立标题历史不修改；Agent 旧 `title` 字段保留兼容，新增展示字段单独返回。
标题支持 CommonMark ATX/Setext，忽略开头 front matter 与代码块，以纯文本提取。
普通 Page 仍为平面文件集，入口必须是该版本中可安全读取的 UTF-8 文本文件。

文件字节相同但入口变化也产生新 Revision。恢复历史时复制其入口与保存的标题；
不能用当前解析规则重写旧版本标题。没有有效变化时返回当前版本。

## 管理 JSON 与保存

接口前缀为 `/admin/api`，提供独立 OpenAPI。会话查询可返回初始化状态；受保护资源
要求主 Token 会话，所有写请求要求同源与 `X-CSRF-Token`，登录与首次设置也校验
来源。凭据响应禁止缓存且不进入前端查询缓存、URL、浏览器持久存储或日志。

版本清单提供准确下载和可用预览地址、可编辑性、大小、摘要、入口及保存的标题。
前端依据清单展示，不猜测受保护文件地址。读取和编辑使用同一前端 Markdown 渲染器。

网页文件保存明确使用 `overwrite_latest`：编辑指令和上传文件在写事务内应用到
最新版本，保留未改文件；版本回读与是否取代较新版本一起返回。重试使用原操作标识，
结果未知时不产生第二次新操作。移动、标签和生命周期仍使用既有并发校验。

附件引用调整仅作用于当前文件集的明确 Markdown 目标。界面按文件、行列和上下文
列出建议，默认选择可靠命中。共享引用定义显示全部影响；文本变化使旧建议失效。
应用只改变当前编辑状态，保存再原子提交；不改历史、代码块或其他页面。

## 库内 Skill

`library_skills` 保存稳定资源身份与当前版本指针，`library_skill_revisions` 和
`library_skill_files` 保存不可变整包。Skill 可保留内部目录，拒绝绝对路径、点路径、
反斜杠、名称规范化冲突和文件/目录冲突；根 `SKILL.md` 必须为有效 UTF-8。
稳定 Skill 身份不随名称变化，名称在同一知识库唯一。

Agent 在 `/api/v1/libraries/{library_id}/skills` 发现资源，按准确版本 manifest
下载全部文件。只读与只写权限分别校验，不因结构发现授予文件读取权。已有内置
通用 Skill 下载地址继续有效，不把实例私有规则打进公开应用资源。

本机安装记录线上 Skill 身份、版本与逐文件摘要。每次新任务先读取库 README 和
版本摘要；版本一致复用安装版，新版校验后更新。本地规则分叉先展示差异，保留用户
选择；入口和凭据配置与安装包分离。服务端不推送安装，也不执行包内文件。

## 迁移和验证

迁移只增加版本展示与 Skill 数据，不改写既有正文、凭据或标识符。已有历史允许无
入口，禁止为便利回填文件猜测。备份显式支持新 schema，校验全部新增版本和文件
摘要；存在新业务数据时拒绝丢失数据的降级。旧版备份仍按其准确格式校验。

只增加覆盖新关键不变量所需的检查，复用现有浏览器旅程。前端构建、类型与必要交互
检查纳入 CI；不降低覆盖率门槛，不用排除或跳过测试掩盖问题。
