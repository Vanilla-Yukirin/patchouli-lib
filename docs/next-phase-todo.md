# 下一阶段改造清单

本清单只列工作项，不代表功能已经实现或设计提案已经获得兼容性批准。具体目标、
边界、待决定事项和验收证据见[下一阶段产品与接口设计](proposals/next-phase-product-and-api.md)。
实施时应按依赖拆分成可审查的改动，不要求一个 Pull Request 完成全部程序修改。

## 设计与迁移准备

- [ ] 核对现有数据、公开接口、客户端和管理面板的兼容性边界。
- [ ] 确认多文件 Page、搜索索引、凭据保存与多 Library 授权的详细方案。
- [ ] 为数据库迁移、索引重建、备份恢复和旧客户端制定回退路径。
- [ ] 更新公开提案的状态与决策记录；未经接受不启用生产索引迁移。

## 内容模型与写入

- [ ] 完成多 Library、Section、Book 和 Page 的管理操作。
- [ ] 将 Page 扩展为无嵌套目录的多文件内容单元。
- [ ] 提供文件清单、下载、引用和多文件 Revision 历史。
- [ ] 实现声明时间缺省、校正及与服务器时间的区分。
- [ ] 实现相同内容不新增 Revision、幂等重试和写后回读校验。
- [ ] 实现 Page 移动、软删除、回收站、恢复与历史浏览。
- [ ] 实现 Tag 的创建、关联、列举与筛选。

## 凭据、授权与审计

- [ ] 设计单人管理入口与首次设置流程。
- [ ] 实现 Agent／设备身份、凭据展示、复制、轮换和吊销。
- [ ] 实现每个凭据对多个 Library 的读／写开关，不细分 Section。
- [ ] 扩充调用方身份查询，展示名称、说明与有效权限。
- [ ] 区分内容活动与 API 请求记录，并提供受保护的查看界面。

## 搜索与读取

- [ ] 修订并审查现有 FTS 提案，移除与目标容量冲突的 Alpha 限制。
- [ ] 实现字符 n-gram 倒排索引、当前 Revision 更新和重建。
- [ ] 实现关键词、Tag、声明时间及 Library 范围的组合查询。
- [ ] 实现以 Page 为单位的 Top K 结果、稳定排序和准确引用。
- [ ] 使用代表性中英文语料验证相关性、容量和查询延迟。

## 管理后台

- [ ] 建立左侧导航、近况首页与内容活动时间线。
- [ ] 建立知识库网格、层级浏览、Page 预览及版本视图。
- [ ] 建立 Agent／设备和 Token 管理页面。
- [ ] 建立 API、Skill 与 MCP 的只读说明及响应预览。
- [ ] 建立人类搜索界面、Tag 浏览和回收站界面。
- [ ] 建立 AI 原生接入页面与复制指令流程。

## Agent 接入与验收

- [ ] 发布公开可复制的无密钥接入指令。
- [ ] 提供凭据保护下的 Skill 文档及版本清单。
- [ ] 编写不要求安装专用 CLI 的标准 HTTP 与多系统调用示例。
- [ ] 指导本机交互式填写 Token，不把 Token 发给模型或写入受跟踪文件。
- [ ] 逐设备核对可达入口、凭据身份、Skill 安装、读取与上传能力。
- [ ] 对分散资料先做来源清点、去重和小批量试导入，再核对准确 Page 与 Revision。
- [ ] 验证单文件、多文件、重复上传、版本更新、回收站和搜索的端到端流程。
- [ ] 检查公开仓库内容、日志、测试夹具和界面是否泄露私有信息。
