# ADR 0005：管理工作区与知识库 Skills

- 状态：已接受方向，随本轮实现验证
- 日期：2026-10-20
- 取代：ADR 0003 中的密码登录和服务端页面渲染决定；其余鉴权与同源约束保留

## 决定

管理界面使用独立 `web/` React 静态工程，运行时与 JSON 管理接口同源。Python
不再生成管理页面或渲染 Markdown。管理接口仅接受主 Token 建立的签名会话 Cookie，
写操作继续验证 Origin 和 CSRF；公开 Agent 接口继续仅接受其原有 Bearer 凭据。
首次设置保留部署者的一次性设置令牌；未设置主 Token 的已有安装可用本机
`patchouli-master-token initialize` 初始化，已有主 Token 的恢复继续使用原恢复命令。
移除密码登录及其配置和命令，不删除 Agent 侧的 Operator 凭据。

入口文件与展示标题属于准确 Revision，不属于可变页面设置。网页选择入口文件，
Agent 文件集写入可省略并得到提示。没有入口文件时不推断；设置或更换入口形成
新版本。标题在写入时从 Markdown 入口的首个一级标题提取，提取不到为“无标题”。
旧 `title` 输入保留其标识符与兼容含义，不用于新网页的展示标题，不改写旧历史。

### 旧归档管理阅读兼容（2026-10-21 补充）

仅对没有 `revision_presentations` 记录的历史版本，管理界面在读取时推导唯一
Markdown 或唯一 README 入口，从准确版本的正文提取首个一级标题；没有一级标题时
使用旧 Page 标题，仍缺失再用文件名。多篇 Markdown 且无唯一 README 时不猜正文，
仍保留旧页面标题。已有显式展示记录（包括明确未选入口）优先。

此项取代上文对旧版本“一律不推断”的管理阅读决定，不回填表、不新增版本、不改
原字节与历史。写入、相同内容判断、恢复、Agent 展示字段和搜索索引规则保持原契约；
管理列表采用批量只读解析，正文读取复用已校验的准确版本文件集。

网页编辑以明确保存为边界，覆盖保存基于事务内的最新版本；未改文件取自最新版本，
修改、移除与改名按本次编辑提交。旧版本保留，结果告知是否覆盖了较新版本。Agent
既有条件写入不变。入口、文件与标题作为一次原子版本保存；无变化不增加版本。

每个知识库的 Skills 是直属、独立的多文件资源；包内允许目录，普通 Page 仍使用
平面文件名。Skill 根入口为 `SKILL.md`，历史保存完整快照，服务端只存储和分发，
不执行脚本。读取与写入沿用知识库独立范围，管理网页通过主会话操作。
