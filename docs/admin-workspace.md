# 管理工作区

本文描述新管理工作区的开发实现。发布、迁移和真实服务验收以相应 PR 与私有部署
记录为准；合并源码不表示现有实例已自动升级。

## 启用与首次设置

设置独立的 `PATCHOULI_ADMIN_SESSION_SIGNING_SECRET`（32 至 1024 个 UTF-8 字节）
即可启用同源 `/admin`。使用 HTTPS，并为反向代理配置准确的可信代理来源；不需要
域名白名单，不使用任意来源代理信任。管理会话签名材料不与主 Token 或其他密钥共用。

新实例可以配置独立 `PATCHOULI_ADMIN_SETUP_TOKEN`，在首次设置页面提交该部署证明，
设置并确认自己的主 Token。成功后移除私有配置中的一次性设置证明。没有证明时，
部署者在持有数据库访问权限的本机交互式终端运行：

```sh
patchouli-master-token initialize
```

命令隐藏输入，不把真实 Token 放进命令参数、仓库或日志。已有主 Token 的本机恢复
继续使用 `patchouli-master-token recover --confirm-local-reset`；先阅读命令帮助并
确认其会使旧管理会话失效。恢复不删除普通设备凭据或业务文件。

之后网页登录只输入主 Token，不需要用户名、密码或 Operator Token。密码登录、
旧密码配置和 `patchouli-admin-password` 命令已退役；只持有旧密码的安装须先用上述
本机初始化或部署证明完成过渡。Agent 侧的既有 Operator 凭据不因此删除。

## 阅读、编辑与附件

- 顶部集中全局菜单；进入知识库先看 README、Skills 和分区概览。
- 分区内左侧展开书籍与文档，右侧阅读；窄屏通过目录抽屉使用相同功能。
- 每个版本显式保存入口文件。未指定时显示“无入口文件”，可选择后保存为新版本。
- 展示标题由入口 Markdown 的第一个一级标题在保存时提取，没有则显示“无标题”。
  文件名和稳定地址不随展示标题改变。
- 文本使用源码与预览编辑，二进制文件可下载或替换。只有“保存”才生成正式版本，
  未改附件保留；没有自动保存或跨设备草稿。
- 网页文本保存以最新版本为基础覆盖本次编辑，旧版本仍在历史中；其他元数据操作
  保留并发校验。Agent 的条件写入协议不变。
- 附件改名会列出当前文件集内可识别的 Markdown 引用，按行列和上下文勾选要调整的
  项目；应用后仍须保存，不批量修改其他文档或历史。

知识库内搜索默认限当前库，库外搜索为全局入口；没有结果时不会自动扩大范围。
SHA-256、字节数和内部 ID 放在可展开的技术信息中。发生时间按浏览器实际时区显示，
输入同时预览将提交的 UTC，不写死时差。移入回收站后的提示可撤销，严格使用本次
删除的状态条件；若状态变化或结果未知，提示核对回收站，不自动覆盖或重试。撤销
刷新目录，但不跳走当前编辑页。弹窗关闭返回仍有效的打开控件。

## Skills 与设备接入

每个知识库有独立 Skills 集合，一个 Skill 包可以包含 `SKILL.md`、脚本、参考资料和
目录。网页直接查看、编辑、保存、复制和下载；保存发布新版本无需重新部署应用。
服务器不执行包内脚本，不跨知识库联动修改。

Agent 读取知识库 README 后发现该库 Skills，按准确版本清单下载并核对全部文件。
本机正式安装并保留版本记录；新任务首次访问库时检查线上版本，有更新再按宿主授权
同步。本地规则分叉先展示差异，私有入口与 Token 配置保留在包外。

凭据管理分别设置读取与写入范围：“仅指定知识库”选择允许项，“所有知识库”选择
排除项；全部模式包含以后新建的库，写入不自动包含读取。设备凭据不授予宿主机权限。
凭据管理地址为 `/admin/credentials`，旧列表地址 `/admin/agents` 会跳转到此入口。

### 旧页面链接

旧 GET 页面通过 `web/src/legacy-routes.ts` 集中转到新工作区，不自动执行原页面中的
移动、删除、恢复或授权操作。表内路径均以 `/admin` 为前缀：

| 旧页面 | 新入口 |
| --- | --- |
| `/libraries/{l}/sections/{s}/books/{b}/pages/{p}` | `/libraries/{l}/pages/{p}` |
| 上述文档的 `revisions/{n}`、历史文件或恢复表单 | 对应准确历史版本的只读页面 |
| `/libraries/{l}/callers/{c}`、凭据授权表单 | `/credentials/{c}?library_id={l}` |
| 库回收站、分区回收站与其旧详情 | 所属知识库的回收站 |
| `/libraries/{l}/tags` | 按该库筛选的标签页 |
| `/guide`、`/agent`、`/mcp` | `/help`、`/help/agent`、`/help/mcp` |
| `/setup`、`/master/setup` | `/settings` |
| `/agents`、`/onboarding-tickets` | `/credentials` |

未知子路径返回 404，不落到知识库或分区概览。没有精确对应页的旧身份请求记录链接
也返回 404，不扩大为全局请求记录。旧分页、预览选择与语言查询不改变所选历史版本。
成功写入即使离开页面也会刷新缓存并提示，但不会将用户从新编辑区跳走；提示只在
发起操作的同一次管理登录内有效。

“生成接入小票”在凭据页打开抽屉，直接生成并复制短期一次性接入指令，不再跳转到
第二张管理页面。Agent 兑换前确认名称、说明、期限、独立范围、本机保存位置和变量
名。长期 Token 由本机脚本保存和验证，不进入聊天或模型上下文。结果未知时先在凭据
管理核对，不盲目重复兑换。

## 构建与安全

前端源码在 `web/`；开发使用 Node.js 24，运行服务不需要 Node。执行 `npm ci --prefix web`
和 `npm run build --prefix web` 生成包内静态资源，镜像使用独立构建阶段完成相同过程。
构建 Python 分发包前也先执行该前端构建；wheel 与 sdist 均包含生成的静态资源。
浏览器与管理 JSON 同源，使用 HttpOnly、SameSite=Strict 会话，写请求校验 Origin 与
CSRF；管理接口不接受设备 Bearer，Agent API 不接受管理 Cookie。

Token 不进入浏览器持久存储，敏感响应禁止缓存。Markdown 不执行原始 HTML、脚本
或远程图片；只显示服务端清单允许的同版本图片预览。所有脚本和样式同源打包。

### 仅在加密私网中使用 HTTP

只有在受信任的加密私网中才显式设置 `PATCHOULI_ADMIN_ALLOW_PRIVATE_HTTP=true`。
HTTPS 的 Cookie 始终保留 Secure；不要切换运行环境、关闭 TLS 校验或跳过鉴权来
修复入口问题。多个入口分别保存浏览器会话，但同一实例使用同一主身份和业务数据。

工作区没有 Shell、SQL、容器、发布部署或备份恢复权限。运维仍由获授权的部署者在
独立流程中完成，升级前保留已验证的精确格式备份与上一镜像身份。

本轮变更包含检索投影版本更新。部署者应在停写窗口完成数据库迁移，再用目标版本执行
`patchouli-search-index rebuild`，之后才恢复 API。该命令只重建可再生索引，不改正文、
历史或凭据；旧投影未重建时检索会拒绝使用，而不会返回不一致的标题。
