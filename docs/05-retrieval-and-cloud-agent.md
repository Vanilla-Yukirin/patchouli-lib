# 检索接口与托管 Agent 的职责

> 开发分支已实现多 Library、Tag、声明时间及字符倒排搜索，尚未合并或部署。
> 查询语义见[当前 Page 搜索 v2](proposals/current-page-search-v2.md)，整体交付见
> [下一阶段清单](next-phase-todo.md)。索引未就绪时返回 503。

## 检索边界

新搜索以当前凭据实际可读的 Library 为边界；可指定其中一部分，不指定时搜索全部
可读库。旧 Section 模式凭据继续受原分区授权约束，不因新增接口自动扩权。
查询只针对未删除 Page 的当前 Revision，历史内容须按明确版本读取。

## 直接查询接口

访问层应支持以下结构化操作：

- 列出 Section 和 Book；开发分支允许用可选 `library_id` 发现获读授权的目标库；
- 按显式 Library／Section 列出当前 Page，或按 Library／稳定 Page ID 查询当前位置；
  返回当前 Section／Book 和准确文件清单链接，不返回文件正文；旧归属库 Page 路由
  仍保留原范围；
- 按关键词数组搜索 Page 标题、文件名和明确识别的当前文本文件；
- 按 Tag 和声明时间过滤；类型及任意状态过滤不属于当前搜索契约；
- 按 ID 获取 Page 或明确指定的 Revision；
- 每项结果都返回稳定引用。

正则表达式、全文检索语法和语义查询需要不同的输入字段与资源限制。不得把用户输入
插入数据库或 Shell 表达式中。

## 检索流水线

开发分支的搜索流程为：

1. 核对当前凭据、目标 Library 和旧模式下的 Section 授权；
2. 按关键词 OR 召回当前 Page 的字符倒排候选，核实连续字面匹配；
3. 应用 Tag OR 与声明时间区间过滤；Tag 名不作为关键词正文；
4. 按固定字段权重确定性排序，按 `limit` 返回当前 Page、命中来源、准确版本引用
   和有界纯文本摘录；在同一 POST 查询体内携带返回的 `next_cursor` 继续翻页。

摘录取自当前版本已授权的规范化索引文本，而不是原始文件字节；二进制独占 Page
可能没有摘录。游标不放进 URL，也不能自行构造；查询、授权或可见结果变化后收到
`400 invalid_cursor`，应不带游标重新搜索。生产配置必须提供检索游标签名密钥；
这些开发分支能力尚未合并、部署或完成目标容量验收。摘要／Derived Fact 召回、
模型辅助综合仍是后续扩展，不属于当前搜索响应。空条件调用应改用结构浏览接口。

嵌入检索属于可选扩展。它必须证明比基线有可衡量的价值，且在设计上不得强制依赖
外部提供方。

## 托管 Agent

部署可以配置托管检索 Agent，其职责包括：

- 规划并执行范围有限的搜索；
- 只在需要时请求额外源内容；
- 生成带 Page 或 Revision 引用的简短回答；
- 生成摘要或整理建议；
- 说明使用了哪个提供方和哪些检索步骤。

公开契约与提供方无关。任何模型名称、账号、端点或部署区域都不是项目范围的要求。

## 调用方 Agent

本地工具、MCP 客户端和 Agent Skill 以通过身份验证的调用方身份工作。它们可以在
获授作用域内创建 Page、追加 Revision、搜索、下载和回应建议。

大段文本应从文件或数据流上传，而不是嵌套在多层命令行 JSON 中。凭据应放在操作
系统机密存储中或通过环境变量注入，绝不能出现在请求示例或受跟踪配置中。

### 多入口与写入重试

同一服务可以提供公网与私网入口。客户端仅使用用户明确提供的入口，并在切换后
重新核对身份和权限；身份或凭据 ID 相同不能证明两个入口共享写入状态。

跨入口重放写入请求的部署前提是：两端共享同一套当前数据库及持久幂等记录，
原入口已提交的写入和对应幂等记录在备用入口同样可见。管理员须依据实际部署配置
确认此前提；独立实例、延迟副本或恢复后的数据库不能默认视为满足此前提。
无法确认时，客户端停止跨入口重放，保留原请求并交由用户核验上传结果。

即使确认共享，重试仍须保留原幂等键、目标、元数据、全部文件字节及适用的
`If-Match`，遵守具体接口的重试契约。超时不表示未写入，不得换键再次新建；
冲突或无法确认的结果应先核验，不能靠切换入口自动覆盖。

## 导入

核心 API 应提供幂等、可观测的单项写入。初期可由客户端在这些原语之上编排批量导入。
只有指标证明有必要时，才应添加专用批量协议。

## 评估

检索质量需要一套带版本的评估语料，其中包含合成或可再分发文档、问题、相关来源
判断、延迟和资源测量。排序变更成为默认方案前，应先在该语料上评估。
